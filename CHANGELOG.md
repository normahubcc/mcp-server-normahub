## [0.2.6] — 2026-11-25

### Добавлено

- Живой каталог моделей: публичный `GET /api/v1/public/models`, кэш в памяти на
  10 минут, повтор при сбое сети, офлайн-снимок как последний фолбэк.
  Переменные `NORMAHUB_CATALOG_URL`, `NORMAHUB_OFFLINE`.
- Инструмент `normahub_estimate_cost`: стоимость в USD до вызова — токены
  (с учётом кэша входа), изображения за генерацию, видео за секунду по разрешению.
- Streamable HTTP `POST /mcp` — транспорт, который рекомендует спецификация MCP;
  legacy HTTP+SSE сохранён для существующих клиентов.
- `mcpName` и `server.json` — пакет готов к публикации в официальном реестре MCP.
- `src/version.ts`: версия читается из `package.json` в рантайме, одна на весь пакет.
- Типизированные ошибки `NormaHubApiError` (`status`, `code`, `requestId`) и
  валидация аргументов инструментов (`src/args.ts`).
- Прогресс-уведомления MCP при опросе видеозадачи и остановка опроса при отмене.
- `/health` отдаёт версию, число инструментов, аптайм и число активных SSE-сессий.
- `scripts/check-release.mjs` (preflight метаданных) и `scripts/publish.sh`
  (токен только из файла с правами 600/400, временный `.npmrc`, `--dry-run`).

### Изменено

- Версия пакета, баннеры, handshake и User-Agent больше не расходятся.
- Модель для видео по умолчанию берётся из каталога (`NORMAHUB_DEFAULT_VIDEO_MODEL`),
  а не из константы.
- `/v1/balance`: 404 означает «эндпоинт не предоставляется», 401/403 — ошибка.
- Фолбэк на резервный эндпоинт срабатывает по HTTP-статусу, а не по подстроке «404».
- SSE: лимит сессий (64 по умолчанию), keepalive каждые 25 с, корректное закрытие.
- Требуется Node.js 22 (Node 20 снят с поддержки).
- CI: Node 22, `npm run check:release`, `npm pack --dry-run`.

### Исправлено

- Три разные версии в одном релизе: 0.2.0 в баннерах, 0.2.5 в handshake, 0.1.0 в User-Agent.
- Модель по умолчанию `seedance-2.5` отсутствует в каталоге — вызовы падали.
- «30 моделей» в описании, ресурсе и статусе при фактических 34.
- Баланс показывал «Active» при отклонённом ключе.
- Неизвестный инструмент и пустой ответ модели возвращались без объяснения.
- Аудио: файл больше 25 МБ уходил в платный запрос; имя файла не экранировалось,
  MIME всегда был `application/octet-stream`.

### Удалено

- Один тестовый файл на весь сервер заменён набором из четырёх (30 тестов),
  включая реальный запуск stdio-процесса и оба HTTP-транспорта.
